# Tanmay Shakya Task 33

## To-Do List Application

This is a full-stack To-Do List application built using:

- React
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- Add a new todo
- View all todos
- Mark todo as completed
- Delete a todo
- Data stored in MongoDB
- React frontend connected with Express backend
