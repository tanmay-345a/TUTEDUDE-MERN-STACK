## Assignment
This project is a responsive OmniFood-style healthy food delivery landing page created with HTML5 and CSS3, with a small JavaScript menu interaction.

## Required Sections Implemented

1. **Header + Hero / Food Delivery**
   - GOODBYE JUNK FOOD.
   - HELLO SUPER HEALTHY FOOD.
   - "I'm Hungry" button
   - "Show me more" button
   - Dark overlay over the hero image

2. **How It Works**
   - Three numbered steps
   - Phone/food delivery mockups
   - Google Play button
   - App Store button

3. **Meals**
   - Four healthy meal cards
   - Local image assets

4. **Our Cities**
   - Lisbon
   - London
   - Berlin
   - San Francisco
   - Four city cards with local images

5. **Pricing Plans**
   - PREMIUM: $399/month
   - PRO: $199/month
   - STARTER: $19/meal
   - Feature lists with check marks

6. **CTA + Footer**
   - Final call-to-action
   - Navigation and contact information

## How to Run

1. Keep all files in the same project folder.
2. Do not move or rename the `assets` folder.
3. Open `index.html` in a browser.
4. Test every navigation link.
5. Resize the browser to check mobile navigation and responsive grids.

## Responsive Design

The page uses media queries for:
- Mobile navigation
- One-column mobile cards
- Two-column tablet grids
- Flexible hero typography
- Mobile CTA and store buttons

## Image Assets

All page images are stored locally inside the `assets` folder. No external image URLs are required.
