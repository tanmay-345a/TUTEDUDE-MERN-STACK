# ReactJS - Hello World

## Problem Statement

Develop a basic "Hello World" React application.

## Problem Description

This project is a simple React application that displays
the text "Hello World!" on the screen.

## Technologies Used

- ReactJS
- JavaScript
- Vite
- HTML
- CSS

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the localhost link in the browser.

## Output

The application displays:

Hello World!
