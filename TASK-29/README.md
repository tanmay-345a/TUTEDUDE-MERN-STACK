# Shoe Shopping Website

## Project Description

This is a Shoe Shopping Website developed using React.js.

The website allows users to browse shoes, add shoes to the shopping cart, manage the quantity of products and view the total price.

The project uses React Context API to manage the shopping cart data.

## Technologies Used

- React.js
- JavaScript
- HTML
- CSS
- React Context API
- React Router DOM
- Vite

## Features

1. Display different shoes.
2. Add shoes to cart.
3. Increase product quantity.
4. Decrease product quantity.
5. Remove products from cart.
6. Calculate total price automatically.
7. Proceed to Payment page.
8. Back to Shopping option.
9. Credit Card Payment form.
10. Payment success message.
11. Cart is cleared after successful payment.
