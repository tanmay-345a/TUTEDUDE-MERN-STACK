# To-Do List API



## Project Overview



This task focuses on identifying and planning the RESTful APIs required for a To-Do List application using Express.js.


## API Operations



1\. Get all tasks

&#x20;  Method: GET

&#x20;  Endpoint: /api/tasks



2\. Get a single task

&#x20;  Method: GET

&#x20;  Endpoint: /api/tasks/:id



3\. Add a new task

&#x20;  Method: POST

&#x20;  Endpoint: /api/tasks



4\. Update an existing task

&#x20;  Method: PUT

&#x20;  Endpoint: /api/tasks/:id



5\. Delete a task

&#x20;  Method: DELETE

&#x20;  Endpoint: /api/tasks/:id



6\. Update task completion status

&#x20;  Method: PATCH

&#x20;  Endpoint: /api/tasks/:id/status



## CRUD Operations



Create - POST /api/tasks

Read - GET /api/tasks

Update - PUT /api/tasks/:id

Delete - DELETE /api/tasks/:id



## Purpose



These APIs allow the To-Do List application to create, retrieve, update, delete and manage tasks.



## Possible Challenges


\- Maintaining unique task IDs

\- Handling invalid task IDs

\- Validating task information

\- Handling API errors

\- Managing task data properly
