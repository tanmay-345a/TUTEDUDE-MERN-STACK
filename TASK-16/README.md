# Task to cover :
    Objective: 
        The Objective of this assignment is to create a web page that displays student records using HTML and JavaScript. The web page should include some cards showing student details such as name, marks, class, and address. Additionally, a search box should be implemented to filter students by name dynamically.

    Tasks:
        Create an HTML file that includes the following elements:
        > Create an array of student objects with the following attributes:
            >> Name
            >> Marks
            >> Class
            >> Address
        >Render the students records in card format as shown in the sample output using HTML. 
        >Implement a search box that filters students by name dynamically using JavaScript's filter function.

    Instructions :
        > Create an array of student objects, each containing attributes for name, marks, class, and address.
        > Implement HTML markup to display a card format as shown in sample output for student records.
        > Populate the cards with student records retrieved from the array.
        > Implement JavaScript code to handle the following:
            >> Rendering Student records dynamically in the cards.
            >> Implementing a search functionality that filters students by name as the user types  in the search box. 
            >> Ensure that the search functionality updates the displayed student records in real-time based on the entered search text.
        >Use Map Function to populate the entries And Filter function to get students with searched names.
