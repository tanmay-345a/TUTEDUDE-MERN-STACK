## 📌 Project Description

Laundry Wallaha is a modern, responsive, and visually appealing login page designed for laundry service platforms and service-based businesses. The project focuses on clean UI design, user-friendly interactions, and professional front-end development practices using pure HTML and CSS.

This project demonstrates how a real-world authentication page can be structured while maintaining a simple and elegant user experience.

---

## 🚀 Features

### ✨ Authentication Interface
- Secure Login Form UI
- Email Input Field
- Password Input Field
- Login Button
- Forgot Password Link

- Professional Layout
