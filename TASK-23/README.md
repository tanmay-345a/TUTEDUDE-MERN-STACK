# Greenwood Library Website

## Project Overview

Greenwood Library is a modern and responsive public library website
designed to showcase library spaces, collections, events, membership
plans and community services.

The website uses a clean editorial-style layout with responsive
design, interactive hover effects and image-based sections.

## Technologies Used

- HTML5
- Tailwind CSS CDN
- JavaScript

## Website Sections

1. Navigation Bar
2. Hero Section
3. Library Sections
4. Gallery
5. Values / Bento Grid
6. About Section
7. Membership Plans
8. Testimonial Section
9. Contact Call-To-Action
10. Events Section
11. Footer

## Features

- Responsive design for mobile, tablet and desktop
- Sticky navigation bar
- Mobile navigation menu
- Backdrop blur effect
- Interactive hover effects
- Image zoom animations
- Responsive image gallery
- Membership cards
- Popular badge for Student membership
- Event cards
- Contact call-to-action
- Multi-column footer
- Smooth transitions and animations

## Tailwind CSS

The project uses Tailwind CSS through the CDN.

No separate CSS file is required.

## How to Run

1. Download or copy the project folder.
2. Open the `Greenwood-Library` folder in VS Code.
3. Open `index.html`.
4. Run the file using Live Server or open it directly in a browser.
5. Make sure you have an active internet connection because Tailwind
   CSS and the images are loaded through external URLs.
