# Greenwood Library Website

## Project Overview

Greenwood Library is a responsive library website created using HTML
and Tailwind CSS.

The website provides information about the library, its services,
membership plans, events and contact details.

## Technologies Used

- HTML5
- Tailwind CSS
- Unsplash Images
- VS Code

## Website Sections

The website contains the following sections:

1. Navigation Bar
2. Hero Section
3. Explore Our Library
4. Library Gallery
5. Our Values
6. About Us
7. Membership Plans
8. Testimonials
9. Upcoming Events
10. Contact Section
11. Footer

## Features

- Responsive layout
- Navigation links
- Smooth scrolling
- Responsive images
- Hover effects on cards and images
- Membership cards
- Events section
- Contact email link
- Mobile-friendly design

## Tailwind CSS

Tailwind CSS is added using its CDN in the HTML file.

## How to Run

1. Open the project folder in VS Code.
2. Open `index.html`.
3. Open the file in a web browser.
4. The Greenwood Library website will be displayed.

## Project Files

- `index.html` - Main webpage
- `README.md` - Project information and documentation
