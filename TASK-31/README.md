# Simple Web Server using Node.js

## Project Description

This project is a simple web server created using Node.js.
The server uses the built-in HTTP module to handle different
web pages and routes.

## Technologies Used

- Node.js
- HTML
- CSS
- HTTP Module
- File System Module

## Features

- Home page
- About page
- Contact page
- Navigation between pages
- CSS styling
- 404 error page for invalid routes
- Asynchronous file reading

## Routes

- `/home` - Home Page
- `/about` - About Page
- `/contact` - Contact Page
- Invalid route - 404 Page Not Found

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run the following command:

```bash
node server.js
