# React Custom Hook - useFetch

## About the Project

This project demonstrates how to create and use a custom React hook called useFetch.

The hook is used to fetch product data from an API.

## Features

- Fetch data from an API
- Show loading message while data is loading
- Show error message when the request fails
- Display fetched products
- Reuse the useFetch custom hook

## Technologies Used

- React
- JavaScript
- CSS
- Vite

## Custom Hook

The `useFetch` hook accepts a URL as a parameter.

It returns:

- data
- loading
- error

## API Used

DummyJSON Products API
