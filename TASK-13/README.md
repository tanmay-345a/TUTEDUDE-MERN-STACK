# Tanmay Shakya - Task(13): JavaScript - Check if a Number is Even or Odd

# How to Run locally:
    1> Clone repository
    2> Open index.html in browser
    3> Right click on the opened window and open developers tool or inspect element.
    4> Go to Console tab of the developers tool or inspect element.
    5> Referesh the browser
    6> Check the output on console window.

# Task to cover :
    Objective:
        Create a JS program that checks whether a given number is even or odd.
    Tasks:
        > Write a JS program that checks if a given number is even or odd.
        > Use Three four different variables.
        > Console.log a message indicating whether the number is even or odd.
    Instructions:
        Use an If-Else statement to determine if the number is even or odd.
    Sample Output:
        The number 5 is odd.
        The number 10 is even.
