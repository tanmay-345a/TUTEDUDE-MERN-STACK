# Task 27 - React Router DOM

## Aim

To implement navigation between different React routes using React Router DOM.

## Description

This project demonstrates routing in a React application using the
react-router-dom library.

The application contains the following pages:

- Home
- Login
- Signup
- Dashboard

## Technologies Used

- React.js
- React Router DOM
- JavaScript
- HTML
- CSS
- Vite

## Features

1. Navigation between different pages.
2. Home page.
3. Login page.
4. Signup page.
5. Dashboard page.
6. Client-side routing using React Router DOM.

## Routes

| Page | Route |
|------|-------|
| Home | `/` |
| Login | `/login` |
| Signup | `/signup` |
| Dashboard | `/dashboard` |
